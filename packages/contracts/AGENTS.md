# Общий контракт

Здесь находятся общие типы TypeScript и JSON Schema результата Python. Изменение затрагивает всех троих: сначала согласовать его с участниками, затем обновить `docs/CONTRACTS.md`, производителей и потребителей в одной совместимой поставке. Не переносить сюда аналитику или UI. Идентификаторы и суммы в JSON остаются строками. Это общая зона; собственная ветка не даёт автоматического разрешения менять контракт.
